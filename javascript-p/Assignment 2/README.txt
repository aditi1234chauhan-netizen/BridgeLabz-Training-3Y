ASSIGNMENT 2 — JavaScript (Lectures 4–6)

This folder contains one separate JavaScript file for each of the 10 questions from
the supplied assignment PDF, plus this README.

How to run:
1. Open the folder in VS Code, or open a terminal in this folder.
2. Run a question with Node.js, for example:
   node Q1_scope_conflict_resolver.js
3. Repeat for Q2–Q10.

All solutions use plain JavaScript and include comments. Q3 and Q4 intentionally
use Math.random(), so their random outputs can differ each time you run them.
