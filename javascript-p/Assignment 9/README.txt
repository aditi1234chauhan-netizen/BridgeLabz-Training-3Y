Assignment 9 - jQuery Solutions
================================
Each question has its own HTML and JavaScript file:
Q1.html / Q1.js ... Q10.html / Q10.js

How to run:
1. Extract this ZIP folder.
2. Keep each HTML file beside its matching JS file.
3. Open the required HTML file in a browser.
4. An internet connection is required because jQuery is loaded from the official jQuery CDN.

Notes:
- Q9 loads two jQuery versions and uses noConflict() to keep them separate.
- Q10 uses browser localStorage to demonstrate email uniqueness in this browser.
- These are beginner-friendly examples with comments for key jQuery logic.
