ASSIGNMENT 7 - JAVASCRIPT SOLUTIONS

This folder contains solutions for all 9 questions in Assignment 7.
Each Question_X folder contains:
- index.html
- style.css
- script.js

HOW TO RUN:
1. Extract the ZIP file.
2. Open the required Question_X folder.
3. Double-click index.html, or open it in a browser.
4. The JavaScript file is linked at the bottom of each HTML page.

Notes:
- The solutions use HTML, CSS and core JavaScript (ES6+), without frameworks.
- Question 5 loads sample images from picsum.photos, so an internet connection is needed for those images.
- Each question has its own separate script.js file.
